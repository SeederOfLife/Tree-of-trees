# Tree of trees

## France rights tree (1789–2024)

`index.html` is a self-contained interactive page showing the evolution of rights in France as a family tree:

- Each **branch** is a family of rights: democracy, freedoms and equality, work and social, women and family, body and justice.
- Each **mark** is a dated legal text, coloured by the political camp behind it.
- **Shape** shows the type of text: circle for a law, decree or bill, diamond for a constitution or referendum, square for a court ruling.
- **Fill** shows the outcome: solid = adopted, dashed ring = step back, ring with × = rejected or withdrawn, ring with / = struck down.

The overview map shows all 100 texts at a glance. Filter by outcome, camp or text type, search, and tap a row for its official reference, the decisive vote and links to the texts it reverses or builds on.

Open `index.html` in a browser; it has no dependencies.
